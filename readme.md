## Prerequisite:
- Python version>=3.11
- uv
- make 
- gcc
- git

## Generate pgm image stack from m2v file
```
cd tools/mpeg2dec
git apply ../../mpeg2dec.patch
./configure
make
./src/mpeg2dec FILE_PATH.m2v -o pgm
```
`flags.txt`, `frame_period.txt` and pgm files are saved in the `mpeg2dec` directory.  

## Run conversion.py
```
uv sync
uv run conversion.py IMAGE_PATH [ --display --save [OUTPUT] --ips [N] --bob --bottom_field_first ]
```
`IMAGE_PATH`: path to image stack generated by mpeg2dec at previous step. \
`--display`: display images in window. \
`--save`: save images in `OUTPUT` directory if multiple images or `out.ppm` if one image is processed. \
`--ips`: usefull only if `display` flag is active and if a pile of image is in input. image displaying rate. `ips` is red from the `frame_period.txt` file if exists, else `ips = 25` \
`--bob`: bob deinterlacing, works only if `flags.txt` is in the `IMAGE_PATH` directory \
`--bottom_field_first`: forces field order \

If no optionnal flags, program save images in `out` directory or in `out.ppm` file

## Example

The following commands displays the bw_numbers.m2v video with bob deinterlacing (execute from project root):
```
cd tools/mpeg2dec
git apply ../../mpeg2dec.patch  # only do this once
./configure # only do this once
make # only do this once
./src/mpeg2dec ../../videos/elementary/bw_numbers.m2v -o pgm

cd ../../
uv sync # only do this once
uv run conversion.py tools/mpeg2dec --display --bob
```
